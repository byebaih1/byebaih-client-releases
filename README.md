# Byebaih Client — Pixelmon Edition

Download the latest installer from [Releases](https://github.com/byebaih1/byebaih-client-releases/releases/latest).

Install version 3.8.0 once to enable future automatic update downloads. Open Settings to install a downloaded update after closing Minecraft.

Includes Pixelmon 9.3.16 for Minecraft 1.21.1 / NeoForge 21.1.248, plus Sodium, Iris, JourneyMap, JEI, FerriteCore, ModernFix, EntityCulling, Dynamic FPS and CustomSkinLoader 14.21.

The Skins page accepts a Minecraft PNG and Classic/Slim. Request a one-time linking code from the ARBUNG PIXELMON owner before uploading your skin. Players using this client or the matching pack load shared skins from the same service.

CustomSkinLoader is included unmodified as part of the modpack. Its license is included in the JAR. [Original project and matching source](https://github.com/xfl03/MCCustomSkinLoader/tree/v14.21).

This repository distributes compiled installers, update metadata and download documentation. The original launcher project is kept separately.
